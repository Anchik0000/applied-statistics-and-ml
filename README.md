# Прикладная статистика, математическое моделирование и ML

Коллекция исследовательских проектов по математической статистике, вероятностному моделированию и машинному обучению. Репозиторий включает матричные реализации алгоритмов с нуля на NumPy, байесовский анализ, стохастические языковые модели и строгий отбор признаков через статистические тесты.


## Структура репозитория и проекты

### 1. [Статистический отбор признаков и бинарная классификация](./01-statistical-feature-selection-ml/)
* **Задача:** Прогнозирование исходов (выживаемость персонажей) с минимизацией переобучения и устранением информационного шума
* **Методология:**
  * Обработка пропусков и One-Hot Encoding категориальных признаков
  * Анализ мультиколлинеарности через корреляционные матрицы
  * Фильтрация пространства признаков с помощью теста независимости $\chi^2$ (Хи-квадрат) и ранговых корреляций Спирмена/Кендалла (отобрано 23 значимых фактора из 41)
  * Сравнительное обучение логистической и линейной вероятностной моделей
* **Результат:** Достигнуты метрики **F1-Score = 0.894** и **Accuracy = 0.824** на отложенной тестовой выборке


### 2. [Матричный МНК (OLS) и дисперсионный анализ (ANOVA) с нуля](./02-matrix-ols-and-anova/)
* **Задача:** Реализация множественной линейной регрессии и факторного анализа без высокоуровневых библиотек с валидацией условий теоремы Гаусса-Маркова
* **Методология:**
  * Реализация оценки параметров $\hat{\beta} = (X^T X)^{-1} X^T Y$, вычисление стандартных ошибок, t-статистик, p-values и $R^2$ через численные операции NumPy
  * Реализация классов One-Way ANOVA и модели ковариационного анализа (ANCOVA)
  * Диагностика остатков: анализ гетероскедастичности, проверка нормальности распределения ошибок (Q-Q plot) и мультиколлинеарности
* **Результат:** Собственная реализация проверена сопоставлением с библиотекой `statsmodels` — расхождение в коэффициентах составило менее $10^{-13}$. Обоснована робастность оценок на больших данных через ЦПТ


### 3. [Байесовский анализ, HDR-интервалы и отбор моделей](./03-bayesian-inference-model-selection/)
* **Задача:** Исследование методов точечного и интервального байесовского оценивания, а также байесовского сравнения классификаторов (акустические данные Spotify)
* **Методология:**
  * Аналитический вывод смещения, дисперсии и MSE для Пуассоновской модели с сопряженным гамма-априорным распределением; бутстрап-анализ сходимости
  * Численный поиск интервалов наибольшей апостериорной плотности (Highest Density Region, HDR) через оптимизацию `scipy.optimize.minimize`
  * Сравнение классификаторов Gaussian Naive Bayes на основе предельной функции правдоподобия (Log Evidence) и апостериорных вероятностей гипотез
* **Результат:** Байесовское сравнение позволило строго доказать превосходство подмножества динамических признаков над текстурными (апостериорная вероятность гипотезы ~100%)


### 4. [Стохастическое моделирование: цепи Маркова и симуляция процессов](./04-stochastic-nlp-markov-processes/)
* **Задача:** Вероятностное моделирование естественного языка (NLP) и моделирование динамики систем реального времени во времени
* **Методология:**
  * **NLP:** Токенизация корпуса из 5 книг (2.14 млн токенов, словарь 26k состояний). Построение разреженных матриц переходов цепей Маркова 1-го и 2-го порядка; расчет энтропии генерации
  * **Continuous-Time Markov Chains (CTMC):** Аналитическое решение через уравнения Колмогорова-Феллера ($P(t) = e^{Qt}$), нахождение инфинитезимальной матрицы $Q$ и стационарного распределения ($\pi Q = 0$)
  * **Стохастическая симуляция:** 1000 траекторий методом Монте-Карло по алгоритму Гиллеспи на временном горизонте 31 день
* **Результат:** Модель 2-го порядка продемонстрировала связную генерацию синтаксических конструкций. Симуляция Гиллеспи подтвердила теоретические параметры (отклонение среднего всего 0.05%, попадание в 95% ДИ)
